# Лабораторная 2 — теория для защиты

Страница «Собрать ланч»: карточки блюд, Grid + Flex, hover,
активный пункт меню, sticky footer, адаптив.

## CSS Grid (сетка блюд)

- `.dishes { display: grid; grid-template-columns: repeat(3, 1fr);
  gap: 10px; }` — три колонки равной ширины (`1fr` — доля
  свободного места), отступ 10px.
- Grid — двумерная сетка (строки и колонки сразу), Flex —
  одномерный (в строку ИЛИ в столбец).
- `repeat(3, 1fr)` = `1fr 1fr 1fr`.

## Flex в карточке

- `.dish { display: flex; flex-direction: column; }` — элементы
  идут сверху вниз.
- `.dish-name { flex-grow: 1; }` — название растягивается и толкает
  вес и кнопку вниз: кнопки и вес во всех карточках ряда на одном
  уровне, даже если название заняло две строки.
- Меню: `.site-nav ul { display: flex; gap: 15px; flex-wrap: wrap; }` —
  `gap` — отступ между флексами, `wrap` — перенос на новую строку.

## Hover и контекстный селектор

- `.dish:hover { border: 2px solid tomato; }` — рамка при наведении.
  Базовая рамка `2px solid transparent` — чтобы страница не дёргалась
  при появлении границы.
- `.dish:hover button { ... }` — контекстный селектор (через пробел):
  «кнопка ВНУТРИ hover-карточки». Так меняется фон кнопки.
- `cursor: pointer` — рука вместо стрелки.
- `filter: drop-shadow(...)` — тень по контуру блока.
- `border-radius: 35px` — скругление.

## Активный пункт меню

- Текущей странице вручную ставим `class="active"` на её ссылку
  (на index — «О нас», на lunch — «Собрать ланч»).
- `.site-nav a.active { color: tomato; }` — класс (0,1,1) сильнее тега,
  поэтому перебивает обычный цвет ссылок.

## Sticky footer

- `body { display: flex; flex-direction: column; min-height: 100vh; }`,
  `main { flex: 1 0 auto; }` — main растягивается и прижимает футер
  к низу вьюпорта, если контента мало. `100vh` — 100% высоты экрана.

## Адаптив

- `<meta name="viewport" content="width=device-width,
  initial-scale=1.0">` — без него мобильный браузер показывает
  «уменьшенную десктопную» версию и media queries не работают.
- `@media (max-width: 800px) { ... }` — правила внутри действуют,
  только если ширина ≤ 800px. Брейкпоинты: 800 (сетка 2 колонки,
  меню space-between), 600 (меню в столбец по центру, сетка 1 колонка,
  h1/h2 по центру), 400 (мелкий шрифт таблицы).
- `justify-content: space-between` — равные промежутки между
  элементами, крайние прижаты к границам (без отступа до контейнера).
- `align-items: center` — центрирование по поперечной оси (при
  `flex-direction: column` поперечная ось — горизонталь).

## Что могут спросить

1. Чем Grid отличается от Flex? — Grid двумерный, Flex одномерный.
2. Что делает `1fr`? — доля свободного места в гриде.
3. Как выровняли кнопки? — колонка flex + `flex-grow: 1` у названия.
4. Что такое контекстный селектор? — `.dish:hover button`, пробел =
   «потомок внутри».
5. Как работает sticky footer? — flex-колонка на body + `flex: 1` у main.
6. Зачем viewport? — без него нет мобильного масштаба и media.
7. Что такое специфичность? — id > класс > тег; `a.active` бьёт `a`.
8. `gap` vs `margin`? — gap только между элементами, крайние без отступа.
